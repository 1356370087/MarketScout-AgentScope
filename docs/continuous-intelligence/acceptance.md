数据库测试实际执行了个人及计划两层费用预留：个人额度拒绝时不会创建计划费用；计划拒绝时释放未发出模型请求的个人预留；重复结算不重复计费，未知结果继续占额。租约过期的旧 Worker 无法提交结果，已经提交的研判重放不再调用模型。

资料和知识测试使用真实 PostgreSQL、确定性解析及 HTTP 模拟服务，覆盖负责人和同知识库管理者审阅。没有发布资料时不能生成正式知识引用；原始内容和证据引用不匹配被拒绝。事实发布与撤回、Wiki 发布进入同事务事件；来源工作项用于抑制自触发。补充研究保留历史成果，延迟的旧审阅任务不能转换新的 Run。

所有真实数据库连接都指向指定远程服务。业务验收库为 `marketscout_intelligence_acceptance_20261108_final`；框架测试使用独立的 `marketscout_intelligence_runtime_acceptance_20261108`，避免旧测试直接在 `public` 建框架表与业务知识库表重名。测试进程清除了继承的 HTTP/SOCKS 代理变量，用户本地配置没有被改写。

## 容量模拟

实际 PostgreSQL 中建立 20 个计划、200 条来源，通过采集 Worker、200 个持久变化事件、批次研判和派工，使用 HTTP 与模型模拟服务及等待中的研究执行器，验证 4 个自动研究及 1 个模拟人工研究并行；额外研究保持排队。另用真实原生恢复账本验证所有启动/恢复入口共用自动并发限制及单计划限制。

空闲槽位下，事件持久化到派工最大 **17.49 秒**，事项创建到派工最大 **2.05 秒**；20 次反馈请求的 P95 为 **52 毫秒**，取消确认为 **49 毫秒**。原始结果见 `capacity-final.json`。这不包含外部模型耗时，不代表真实 Gateway、MQ、HTTP 来源和模型同时承载此负载的完整部署验收；取消是单次测量，执行侧仍在下一安全检查点应用。

## 真实模型配对比较

在 Docker 中启动了独立 LiteLLM 与 Redis 验收服务，使用独立远程 LiteLLM 数据库；未启动或停止用户的其他服务。代理团队硬额度为 10 美元，两个配对试验各限 4 美元，另一次 P0 复测限 2 美元。实验预算包含研究、Judge 及未决费用，费用不能因试验中断直接清零。

基线从开始实现前的源码与已有工作区修改重建；候选是恢复质量门禁后的冻结快照。固定工具环境使用同一 24 个任务、每题 3 次真实研究、同一评分协议；研究角色统一使用 `if-research-v1`，离线 Judge 使用 `if-quality-v1`。它验证原生研究核心，不是持续 Worker、真实来源、团队身份和 Gateway 的完整联调。

| 冻结快照 | 记录数 | 通过 | 失败 | 无法完成判定 |
| --- | ---: | ---: | ---: | ---: |
| 改动前基线 | 72 | 58 | 11 | 3 |
| 首次候选 | 72 | 55 | 14 | 3 |

配对比较有 23 组完整任务、3 条未决配对；按任务聚合的通过率差为 **-4.35 个百分点**，95% 区间约为 **[-11.59，+2.90] 个百分点**。现有证据**不支持质量提升**，不能以恢复了门禁或 Run 结束作为通过依据。

失败中包含 Judge 结构化输出无效、引用/摘要问题以及现有测试对预算暂停、工具执行的预期不匹配。旧评估入口在没有到达预设审批点时，会中断投影而丢失该条试验的完整输出；当前入口改为保留实际轨迹、费用和交互不匹配记录，没有重新执行已有未决操作。另一次 P0 冻结快照复测使用此修复，其记录单独保留，不能与首次候选混为一组。

P0 复测记录为 **72 条：47 通过、25 失败**。其评估入口包含投影修复，比较器检测到 `comparison_fingerprint_mismatch:rubric`，因此保留为独立试验，没有强行合并配对统计或声称改进。后续持续情报领域的授权、审阅、通知及界面修正由对应数据库和界面测试覆盖；该复测不是最终工作区全部代码的模型验收。

三组试验按冻结价格的账本已结算 **0.958318 美元**，仍保留 **0.271407 美元**未决预留；合计占用 **1.229725 美元**，低于授权的 10 美元。LiteLLM 代理用量口径为 **0.9123044 美元**。未将未决请求视作未执行，也未释放缺少确定回执的费用。验收用代理与 Redis 在验证结束后停止，其他用户服务不变。
